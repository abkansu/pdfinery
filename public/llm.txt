# PDFinery - Free Secure PDF Merger

> PDFinery is a free, privacy-focused PDF merger tool that runs entirely in your browser. Merge, reorder, and organize PDF documents securely without uploading files to any server.

## Core Capabilities
- **Merge PDFs**: Combine multiple PDF files into a single document.
- **Reorder Pages**: Drag and drop interface to organize pages and documents.
- **Privacy First**: 100% client-side processing; files never leave the user's device.
- **No Limits**: Free to use with no file size limits or watermarks.
